**Работает с чатом Твича и/или Ютуба**

---

# Установка

1. Копируете ссылку `[https://laitsberg.github.io/chatRatingFaryma/widget/?channel=ТвичКанал]`
2. Заменяете `ТвичКанал` на свой канал на Твиче
3. Добавляете в OBS как источник браузера

# Подключение Ютуба (необязательно)

Чтобы оценки собирались ещё и из чата Ютуба, нужен бесплатный API-ключ Google (делается один раз):

1. Зайти в [Google Cloud Console](https://console.cloud.google.com/) и создать проект (любое название)
2. **APIs & Services → Library** → найти **YouTube Data API v3** → **Enable**
3. **APIs & Services → Credentials → Create credentials → API key** — скопировать ключ
4. (Рекомендуется) в настройках ключа:
   - **API restrictions** → разрешить только **YouTube Data API v3**
   - **Application restrictions → Websites** → добавить `https://laitsberg.github.io/*`

Дальше добавить в ссылку виджета параметры:
- `&yt_key=КЛЮЧ` — API-ключ
- `&yt_channel=@ВашКанал` — хэндл канала на Ютубе (или ID канала вида `UC...`). Текущий эфир найдётся сам.
  - Вместо этого можно указать `&yt_video=ID_ТРАНСЛЯЦИИ` (то, что после `watch?v=`), но его придётся менять каждый стрим.

Пример (Твич + Ютуб):
> https://laitsberg.github.io/chatRatingFaryma/widget/?channel=ТвичКанал&yt_key=КЛЮЧ&yt_channel=@ЮтубКанал

Пример (только Ютуб):
> https://laitsberg.github.io/chatRatingFaryma/widget/?yt_key=КЛЮЧ&yt_channel=@ЮтубКанал

Голоса с Ютуба в итоговом списке помечаются красным ▶. Если что-то не так (неверный ключ, эфир не найден, закончилась квота) — внизу виджета на несколько секунд появится плашка с ошибкой.

**Про квоту.** Google бесплатно даёт ~10 000 единиц в день, один запрос чата стоит 5.
- Если указан Твич — чат Ютуба читается **только во время голосования**, квоты хватит на сотни голосований в день. Запускать голосование нужно с Твича (модеры Ютуба могут только досрочно завершить идущее голосование).
- Если указан только Ютуб — чат читается постоянно (раз в ~10 секунд вне голосования), чтобы ловить команду `!оценка`. Этого хватает примерно на 5 часов эфира в день.

В режиме «только Ютуб», пока эфир не начался, виджет раз в 30 секунд пытается его найти (~3 единицы за попытку) — так что надолго оставлять OBS открытым до стрима не стоит.

# Инструкция

Модераторы (или стример) могут писать `!оценка` чтобы начать голосование.  

Если надо остановить голосование заранее - снова написать `!оценка` в чате.  
  
Результаты будут показываться 60 секунд. Если нужно их скрыть заранее - снова написать `!оценка` в чате.  

  
Длительность голосования по умолчанию 60 секунд, но её можно изменить:  
- Либо добавить `&time=X` в ссылке виджета где `X` - длительность в секундах  
- Либо использовать `!оценка X` в чате для того чтобы запустить голосование (`X` - либо длительность в секундах, либо в минутах если также после числа указана `м` или `m`, например `!оценка 2m`
